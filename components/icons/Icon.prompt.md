Renders a lucide icon by kebab-case name; use for ALL iconography (never emoji, never hand-rolled SVG).

```jsx
<Icon name="circle-check" size={16} />
<Icon name="loader" spin />          // in-progress
<Icon name="trash-2" size={16} />    // destructive
```

Requires once per page, before use:
`<script src="https://unpkg.com/lucide@0.462.0/dist/umd/lucide.min.js"></script>`

Common names: plus, search, copy, terminal, arrow-right, chevron-down, x, box, bot, plug, layers, network, database, webhook, scroll-text, code, settings, key, pause, play, ellipsis, circle-dot, circle-check, circle-x, circle-pause, circle-dashed, ban, loader, trash-2, hard-drive, cpu, memory-stick, globe, clock.
