Surface container for panels, pickers, and settings sections.

```jsx
<Card>
  <CardHeader>
    <CardTitle>API keys</CardTitle>
    <CardDescription>Manage keys for programmatic access.</CardDescription>
  </CardHeader>
  <CardContent>…</CardContent>
  <CardFooter><Button size="sm">Create key</Button></CardFooter>
</Card>
```

Variants: default (border + xs shadow), elevated (md shadow — popovers), flat, inset (surface-2 well). `interactive` for clickable selection cards.
